# v-activity-lawn

VTuber、ライブ配信者、動画クリエイター向けの活動可視化Chrome拡張機能です。
公式APIに依存せず、YouTube StudioおよびX（旧Twitter）における日々の投稿・配信・ファン交流アクティビティを安全に検知・集計し、GitHubのコントリビューショングラフ（草）のようにブラウザ上で可視化します。

---

## 主な特徴

- **クリエイター活動の草表示**: 日々の動画公開、ライブ配信、コミュニティ投稿、Xでの告知やファン交流を年間53週のコントリビューショングラフとして可視化。
- **公式API完全非依存**: YouTube Data APIやTwitter API v2を使用せず、ブラウザの内部通信インターセプト（MAIN World fetchフック）により完全無料で安全に動作。
- **アカウントBANリスクゼロのパッシブ過去ログ自動収集**: 機械的な外部自動巡回を行わず、ユーザーがYouTube Studioのコンテンツ一覧やXのプロフィールを普段通りスクロール閲覧するだけで、読み込まれた過去ログを自動吸い上げして蓄積。過剰リクエストによる凍結やシャドウバンを100%防止。
- **YouTube公開RSSバックグラウンド定期自動同期**: チャンネルIDを保存しておくことで、Service Workerの定期アラームが1時間ごとに最新動画・配信を完全自動同期（ログイン不要・完全安全）。
- **クリエイター活動量スコア**: 動画編集や長時間配信の負荷・熱量を反映した重み付けスコアアルゴリズムを搭載。
- **推し色・メンバーカラーテーマ**: クリエイター自身のイメージカラーに合わせた草のカラーパレット切替（全6色：グリーン、ピンク、シアン、パープル、レッド、イエロー）が可能。ダークモード対応。
- **完全ローカルファースト**: すべての活動ログはブラウザ内ストレージ（IndexedDB）にのみ保存され、外部サーバーへ一切送信されません。
- **X公式データアーカイブ取込対応**: 数年前の過去ログ全期間を一括復元したい場合は、X公式のデータアーカイブ（ZIP / JS）をドラッグ＆ドロップで即座にインポート可能。
- **SNS共有カード画像生成**: X投稿用（1200×630px）の共有画像をワンクリックでエクスポート可能。プライバシーマスキング対応。

## 技術スタック

- **拡張機能仕様**: Manifest V3準拠
- **言語・ツール**: TypeScript, Vite, Tailwind CSS
- **ローカルストレージ**: IndexedDB (Dexie.js)
- **テストフレームワーク**: Vitest
- **パッケージマネージャー**: pnpm

## 開発・ビルド手順

### 1. 依存関係のインストール
```bash
pnpm install
```

### 2. 単体テストの実行
```bash
pnpm test
```

### 3. 本番ビルド
```bash
pnpm run build
```
ビルド完了後、`dist/` ディレクトリにChrome拡張機能のパッケージが出力されます。

### 4. Chromeブラウザへの読み込み
1. Google Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパーモード」を有効化します。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトの `dist` ディレクトリを選択します。
4. ツールバーに `v-activity-lawn` のアイコンが追加されます。
